8-character code generator

Each number maps to exactly one 8-character code, so codes never repeat and never need to be checked against stored data. Codes can also be turned back into their number.

Issue codes

The counter stands in for a database sequence. Each click takes the next number and encodes it.

Encode a number

Any whole number from 0 to 218,340,105,584,895.

Decode a code

8 characters, letters and digits only. Case matters.

Uniqueness test

Encodes a range of numbers, checks every code for duplicates, and decodes each one to confirm it returns the original number.
